# وصف مشروع STYLE HUB PRO

## الهدف
إنشاء متجر ملابس إلكتروني احترافي باللغة العربية، مع واجهة RTL ولوحة تحكم إدارية.

## أنواع المستخدمين
- **زائر:** يتصفح المنتجات والأقسام.
- **عميل:** ينشئ حسابًا، يدير بياناته، يضيف للسلة، ويطلب المنتجات.
- **مدير:** يدير المنتجات والمخزون والطلبات والعملاء والتقارير.

## الوحدات الأساسية
- إدارة المنتجات والمتغيرات (المقاس/اللون).
- إدارة الأقسام والعلامات التجارية.
- سلة المشتريات.
- الطلبات وحالاتها.
- العملاء والمصادقة.
- الكوبونات والعروض.
- لوحة التحكم والتقارير.

## قرارات تحتاج تحديدًا أثناء التنفيذ
- الاسم والشعار النهائيان.
- الألوان النهائية للتصميم.
- هل المتجر رجالي أم حريمي أم كلاهما؟
- شركة الشحن ومناطق التوصيل وتكلفتها.
- مزود الدفع الإلكتروني المناسب لمصر.
- سياسة الاستبدال والاسترجاع والخصوصية.

## مراحل التطوير والاختبار
1. تهيئة المشروع والاتصال بقاعدة البيانات.
2. تصميم الواجهة والصفحات الأساسية.
3. بناء API للمنتجات والأقسام.
4. المصادقة والصلاحيات.
5. السلة وإنشاء الطلبات.
6. لوحة الإدارة والمخزون.
7. ربط الشحن والدفع بعد تحديد المزود.
8. اختبار الأمان وتجربة المستخدم قبل النشر.
