# الأدوات — شرح مختصر

| الأداة | الاستخدام | هل هي مطلوبة؟ |
|---|---|---|
| VS Code | كتابة وتحرير ملفات المشروع | نعم |
| Node.js | تشغيل الخادم | نعم |
| npm | تثبيت مكتبات JavaScript | يأتي مع Node.js |
| MySQL Server | قاعدة البيانات | نعم |
| MySQL Workbench | إدارة MySQL بواجهة رسومية | اختياري |
| Postman | تجربة طلبات API | موصى به |
| Git | تتبع تغييرات الكود | موصى به |
| GitHub | نسخة احتياطية ومشاركة المشروع | اختياري |
| Cloudinary | تخزين صور المنتجات | اختياري |
| بوابة دفع محلية/متاحة | تحصيل المدفوعات | عند تفعيل الدفع |

## مكتبات Node.js المقترحة
- express: إنشاء خادم API.
- mysql2: الاتصال بـ MySQL.
- dotenv: تحميل إعدادات البيئة.
- cors: ضبط الوصول بين الواجهة والخادم.
- jsonwebtoken: إنشاء والتحقق من JWT.
- bcrypt: تجزئة كلمات المرور.
- helmet: إعداد ترويسات أمان HTTP.
- express-rate-limit: الحد من محاولات الطلبات المتكررة.
- zod أو joi: التحقق من البيانات المدخلة.

تُحدد إصدارات المكتبات وتُثبت عند بدء مرحلة إعداد الخادم.
